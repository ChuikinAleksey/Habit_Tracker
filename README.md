# HabitTracker - Трекер Привычек на Kotlin/Compose

Приложение для отслеживания ежедневных привычек с современным Material Design 3 интерфейсом, построенное на архитектуре MVVM.

###  Особенности
Добавление привычек с названием, описанием и цветом
Просмотр деталей каждой привычки
Удаление привычек с подтверждением
Современный UI на Jetpack Compose
Архитектура MVVM с чистой структурой кода
Навигация с Single Activity + Navigation Component
Material Design 3 с темной темой поддержкой

###  Технологии
* Kotlin - Основной язык разработки
* Jetpack Compose - Современный UI тулкит
* Navigation Component - Навигация между экранами
* Material Design 3 - Дизайн система
* ViewModel + State - Управление состоянием
* Clean Architecture - Чистая структура проекта

### CRUD операции
* Create - Добавление новых привычек
* Read - Просмотр списка и деталей привычек
* Update - Редактирование существующих привычек (в разработке)
* Delete - Удаление привычек с подтверждением

### Планы развития
* Статистика выполнения привычек
* Ежедневные уведомления
* Категории привычек
* Экспорт данных
* Темная тема
* Синхронизация с облаком
